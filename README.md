# Code IA — Tunnel de vente Motion Design IA

## Contenu du projet
- `index.html` : page de vente responsive.
- `assets/video-principale.mp4` : vidéo principale placée dans la première section de la page.
- `assets/realisation-video-02.mp4`, `realisation-video-03.mp4`, `realisation-video-04.mp4` : autres vidéos dans la section « Réalisations Code IA ».
- Cinq affiches/visuels Code IA dans `assets/`, présentés dans les galeries visuelles.

## Paiement
Les boutons d'inscription pointent vers la page Marketou fournie :
https://smiley-design-academy.mymaketou.shop/products/transforme-tes-idees-en-videos-publicitaires-professionnelles-grace-a-lia/checkout

La page affiche 20 000 FCFA comme prix initial barré et 10 000 FCFA comme prix réduit. Vérifie que ce tarif est bien actif sur Marketou.

## Déploiement
1. Décompresse le ZIP sur ton Chromebook.
2. Crée un dépôt sur https://github.com/new nommé `code-ia-formation`.
3. Téléverse `index.html` et le dossier `assets/` complet, sans renommer les fichiers.
4. Clique sur **Commit changes**.
5. Ouvre https://vercel.com/new, importe le dépôt GitHub, choisis **Other** si le framework est demandé, ne définis aucune commande de build, puis clique sur **Deploy**.
6. Teste les quatre vidéos, les cinq visuels et tous les boutons depuis le lien Vercel.

Ne téléverse pas uniquement `index.html` : le dossier `assets/` est nécessaire pour que les vidéos et affiches s'affichent.


## Version allégée
Les vidéos ont été réencodées en MP4/H.264 avec un débit plus léger et les affiches sont en WebP pour réduire le poids du téléchargement. Les chemins sont déjà mis à jour dans `index.html`.
